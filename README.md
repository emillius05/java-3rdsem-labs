## Задание №7: Студент — фильтрация и сортировка

- **Создана модель данных `Student`**: Реализован класс `Student` с полями имени (`name`), возраста (`age`) и оценки (`grade`), необходимыми для выполнения условий задачи[cite: 5].
- **Реализована фильтрация студентов с оценкой выше 8 баллов**: Написан алгоритм отбора элементов из массива/коллекции студентов, средний балл которых строго превышает 8[cite: 5].
- **Выполнена сортировка отфильтрованного результата по имени**: Отобранные студенты упорядочиваются по имени в алфавитном порядке[cite: 5].
- **Реализовано решение задачи двумя способами**: Обработка массива студентов выполнена как через собственный функциональный интерфейс (`@FunctionalInterface`), так и с использованием стандартных функциональных интерфейсов Java (`Predicate<Student>`, `Comparator<Student>`, `Function` и др.)[cite: 5].
- **Проверена корректность обоих подходов**: С помощью модульных тестов подтверждена идентичность результатов работы собственного функционального интерфейса и стандартных интерфейсов Java на различных наборах данных[cite: 5].

## Выполненные требования к архитектуре и коду

- **Соблюдён двойной подход к реализации**: Для фильтрации и сортировки студентов реализованы два независимых варианта — через пользовательский функциональный интерфейс и через встроенные функциональные интерфейсы пакета `java.util.function`[cite: 5].
- **Выдержано разделение ответственности**: Класс-сущность `Student` (пакет `entity`) представляет собой чистую POJO-модель без бизнес-логики, а логика фильтрации и сортировки вынесена в сервисный слой (`StudentService`)[cite: 5].
- **Соблюдена строгая пакетная структура Maven-проекта**: Классы приложения распределены по пакетам (`entity`, `functional`, `service`, `parser`, `reader`), конфигурация логирования размещена в `src/main/resources`, а тесты — в `src/test/java`[cite: 5].
- **Оформление кода приведено к Java Code Convention**: Имена классов, методов, переменных, отступы и модификаторы доступа соответствуют официальному стилю кодирования Java[cite: 5].
- **Реализована проверка входных данных и обработка ошибок**: Предусмотрена валидация данных студентов (имя, возраст, диапазон оценки) и корректная обработка некорректных или граничных значений без аварийного завершения программы[cite: 5].
- **Интегрирована система логирования Log4j2**: Подключены библиотеки `log4j-api` и `log4j-core`, настроен вывод сообщений разных уровней важности (`DEBUG`, `INFO`, `WARN`, `ERROR`) в консоль (с цветовой дифференциацией) и в файлы с ротацией и архивацией старых логов[cite: 5].
- **Подготовлены модульные тесты JUnit Jupiter**: Написаны тесты для проверки сущности `Student`, фильтрации по оценке > 8, сортировки по имени и сравнения результатов обоих способов реализации[cite: 5].
- **Пользовательский интерфейс не реализован**: Работоспособность приложения подтверждается запуском автоматизированных модульных тестов[cite: 5].
- **Настроена автоматизация тестирования через Maven**: Для компиляции и запуска тестов используется команда `mvn clean test` с плагином `maven-surefire-plugin`[cite: 5].
