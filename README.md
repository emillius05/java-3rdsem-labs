## Задание №7: Обработка текста с использованием паттерна Composite

- **Реализована объектная модель составных частей текста**: Построена иерархическая структура на базе паттерна `Composite` (`TextComponent`, `TextComposite`, `SymbolLeaf`, `ComponentType`), позволяющая представлять текст как дерево компонентов: Текст → Абзац → Предложение → Лексема → Слово / Знак препинания → Символ.
- **Реализован поэтапный разбор текста**: С использованием паттерна `Chain of Responsibility` (`TextParser` → `ParagraphParser` → `SentenceParser` → `LexemeParser`) реализован последовательный парсинг исходного текста на составные части[cite: 8].
- **Выполнена нормализация пробельных символов**: В соответствии с условием задачи табуляции и последовательности пробелов заменяются одним пробелом при формировании результирующего текста[cite: 8].
- **Реализована задача Варианта №7**: В сервисе `TextProcessingService` реализована сортировка слов текста по возрастанию доли гласных букв (отношения количества гласных к общему количеству букв в слове) с поддержкой кириллицы и латиницы[cite: 8].
- **Организованы чтение и запись текстовых файлов**: Чтение исходного текста из `data/input.txt` и запись итогового результата в `data/output.txt` реализованы в классе `TextFileManager`[cite: 8].

## Выполненные требования к архитектуре и коду

- **Выдержано разделение ответственности**: Иерархия компонентов текста вынесена в пакет `composite`, парсеры — в пакет `parser`, файловый ввод-вывод — в пакет `io`, а логика обработки текста — в пакет `service` (`TextProcessingService`).
- **Защита инкапсуляции коллекций**: Метод `getChildren()` в `TextComposite` возвращает неизменяемый список (`Collections.unmodifiableList`), предотвращая неконтролируемое изменение дерева извне.
- **Соблюдена строгая пакетная структура Maven-проекта**: Классы распределены по пакетам `composite`, `parser`, `service`, `io`, конфигурация логирования размещена в `src/main/resources`, входные/выходные файлы — в `data`, а тесты — в `src/test/java`.
- **Оформление кода приведено к Java Code Convention**: Имена классов, интерфейсов, перечислений, методов, констант и модификаторы доступа соответствуют стандартам кодирования на Java.
- **Реализована проверка входных данных и обработка ошибок**: Предусмотрена валидация входного текста, компонентов и операций над листовыми элементами с генерацией `IllegalArgumentException` и `UnsupportedOperationException`.
- **Интегрирована система логирования Log4j2**: Подключены библиотеки `log4j-api` и `log4j-core`, настроен цветной вывод логов уровней `DEBUG`, `INFO`, `WARN`, `ERROR` в консоль и запись в файлы с ротацией.
- **Подготовлены модульные тесты JUnit Jupiter**: В `TextCompositeTest` проверяются разбор иерархии текста, нормализация пробелов, сортировка слов по доле гласных букв (Вариант 7), чтение/запись файлов и обработка ошибочных ситуаций.
- **Пользовательский интерфейс не реализован**: Проверка работоспособности выполняется через запуск автоматизированных модульных тестов (`mvn clean test`).
