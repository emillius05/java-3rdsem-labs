## Задание №7: Средство передвижения

- **Разработана система управления транспортными средствами**: Создана модель средства передвижения с регистрационным номером, маркой, моделью, VIN-номером, владельцем и типом движущей силы.
- **Реализовано управление техническим состоянием**: Добавлены возможности заправки/зарядки, ремонта, технического обслуживания и прохождения техосмотра для транспортных средств.
- **Созданы специализированные классы транспорта**: 
  - **Автомобиль (`Car`)**: Добавлено управление количеством дверей и метод активации климат-контроля.
  - **Велосипед (`Bicycle`)**: Добавлено управление количеством передач и регулировка высоты седла.
  - **Самокат (`Scooter`)**: Добавлено свойство максимальной скорости и метод складывания/разкладывания.
  - **Мотоцикл (`Motorcycle`)**: Добавлено поле объема двигателя и проверка натяжения цепи.
  - **Квадроцикл (`QuadBike`)**: Добавлена емкость двигателя и активация полного привода.
- **Реализован сервис управления автопарком (`VehicleService`)**: Реализована фильтрация транспортных средств по типу движущей силы, сортировка по бренду и выполнение массового обслуживания.

## Выполненные требования к архитектуре и коду

- **Применены интерфейсы**: Создан интерфейс `Manageable`, определяющий основные эксплуатационные возможности транспортного средства (заправка, ремонт, обслуживание, техосмотр).
- **Использовано наследование**: Абстрактный класс `Vehicle` содержит общие свойства и поведение транспорта. Классы `Car`, `Bicycle`, `Scooter`, `Motorcycle` и `QuadBike` расширяют его функциональность с учётом особенностей каждого типа.
- **Реализована проверка входных данных**: Добавлена валидация регистрационных номеров, VIN-номеров и числовых параметров (скорость, передачи, объем двигателя, количество дверей).
- **Предусмотрена обработка ошибочных операций**: Для недопустимых и некорректных данных генерируются исключения `IllegalArgumentException`.
- **Соблюдена пакетная структура Maven-проекта**: Классы распределены по пакетам `entity`, `service`, `parser`, `reader`. Конфигурация логирования размещена в `src/main/resources`, а тесты — в `src/test/java` с соответствующей структурой пакетов.
- **Интегрирована система логирования Log4j 2**: Подключены библиотеки `log4j-api` и `log4j-core`. Настроен вывод сообщений в консоль с цветовой дифференциацией уровней и записью в файлы.
- **Добавлено логирование основных операций**: Регистрируются чтение данных из файлов, успешное создание объектов, фильтрация, сортировка и процессы обслуживания транспорта.
- **Подготовлены модульные тесты JUnit Jupiter**: Созданы тесты для проверки сущностей, специализированных методов классов, работы сервисов и фильтрации.
- **Пользовательский интерфейс не реализован**: Работа приложения проверяется посредством автоматизированных модульных тестов.
- **Настроен запуск тестов через Maven**: Для компиляции проекта и выполнения тестов используется команда `mvn clean test`. Для запуска тестов настроен `maven-surefire-plugin`.
