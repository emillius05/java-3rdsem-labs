## Задание: Обработка чисел с плавающей запятой с учётом локали

- **Реализовано чтение данных из символьного файла**: Написан класс `NumberFileReader`, считывающий из файла `data/numbers.txt` информацию об N числах с плавающей запятой с указанием локали каждого числа отдельно.
- **Реализована проверка корректности и парсинг с учётом локали**: Написан класс `LocaleNumberParser`, проверяющий, являются ли записи и значения корректными числами с учётом разделителей конкретной локали (`en-US`, `ru-RU`, `de-DE` и др.), и преобразующий строки в точные значения `BigDecimal`.
- **Реализован расчёт суммы и среднего значения**: Написан сервис `NumberStatisticsService`, вычисляющий сумму и среднее значение прочитанных корректных чисел.
- **Создан собственный класс исключения и предусмотрена обработка ошибок**: Реализовано исключение `InvalidLocaleNumberException`, а также обработаны ошибки при нехватке памяти (`OutOfMemoryError`), отсутствии файла по заданному адресу, отсутствии или некорректности требуемой записи и выходе числа за пределы максимально допустимых значений.

## Выполненные требования к архитектуре и коду

- **Выдержано разделение ответственности**: Чтение входных данных вынесено в класс `NumberFileReader` (пакет `reader`), валидация и парсинг по локалям — в `LocaleNumberParser` (пакет `parser`), расчёт суммы и среднего — в `NumberStatisticsService` (пакет `service`), а модель записи — в `LocaleNumberEntry` (пакет `model`).
- **Соблюдена строгая пакетная структура Maven-проекта**: Классы приложения распределены по пакетам `exception`, `model`, `parser`, `reader` и `service`, конфигурация логирования размещена в `src/main/resources`, а модульные тесты — в `src/test/java`.
- **Оформление кода приведено к Java Code Convention**: Имена классов, методов, констант, переменных и модификаторы доступа соответствуют стандартам оформления кода на Java.
- **Реализована проверка входных данных и обработка ошибок**: Предусмотрена валидация пути к файлу, локалей, формата строк и границ значений с генерацией `InvalidLocaleNumberException`.
- **Интегрирована система логирования Log4j2**: Подключены библиотеки `log4j-api` и `log4j-core`, настроен цветной вывод логов в консоль и запись в файлы (`logs/all.log`) с ротацией и архивацией.
- **Подготовлены модульные тесты JUnit Jupiter**: В классе `LocaleNumbersTest` написаны тесты, проверяющие парсинг чисел по локалям, расчёт суммы и среднего, а также граничные случаи и ошибочные ситуации.
- **Пользовательский интерфейс не реализован**: Проверка работоспособности выполняется через запуск автоматизированных модульных тестов (`mvn clean test`) и класса `Main`.
